Course Project Site Plan | WDD 231 Frontend Web Development

Site Name

Selected Name: Xander Sports and Country Club

Reasoning: The name evokes a sense of high-end prestige, timeless luxury, and exclusivity. It clearly defines the site's scope as an all-encompassing sports community highlighting both premium golf assets and state-of-the-art aquatics facilities while framing it within a professional country club ecosystem.

Proposed Domain: xanderclub.org

Site Purpose

It showcases our luxury facilities and gives real-time updates on daily club operations, like live swimming pool temperatures and golf course availability. Displays Interactive Rosters: It uses JavaScript to instantly pull in and filter a directory of 15+ elite coaches, trainers, and fitness clinics based on what the user wants to see. Enhances User Experience: It features interactive pop-up boxes (modals) for deep-dive details, remembers user preferences (like a preferred sport dashboard) using browser storage, and includes a seamless, step-by-step membership application form.

Target Audience & User Scenarios

The target audience encompasses current high-net-worth members seeking streamlined booking updates, and competitive regional athletes looking to join an elite athletic facility for professional golf coaching or club swim squads.

Scenario 1: Prospective Member Analysis

"I am looking to enroll my children in a structured, competitive swim club and want to review the exact background, metrics, and coaching profiles of the club’s aquatics staff before applying."

Scenario 2: Current Active Golfer Analysis

"What specialized clinics or short-game golf programs are currently hosted by club pros this season, and how can I see explicit schedule availability right now?"

Typography

Heading Font: 'Playfair Display' (Serif)

Used exclusively for main page headings (H1, H2) to cultivate a prestigious, traditional country club tone.

Body Font: 'Inter' (Sans-Serif)

Used for all navigational elements, information grids, descriptions, form modules, and metadata components to secure perfect structural legibility across compact viewports.
